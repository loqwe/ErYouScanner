# MHY_Scanner2

MHY_Scanner2 是基于 [DSVVA/MHY_Scanner](https://github.com/DSVVA/MHY_Scanner) 二次修改的米哈游扫码工具。

本项目为免费开源项目，仅用于学习和研究，禁止商业化用途。请勿提交或公开自己的 Cookie、SToken、MID、UID 等账号敏感信息。

## 二改说明

本仓库在原项目基础上重点修复新版米哈游扫码登录、官服抢码确认、直播间抢码和账号状态检测相关问题，并补充了运行日志，方便定位扫码失败原因。

## 新增功能

- 扫码后确认登录支持用户填写延迟，范围 `0–60` 秒，支持小数；`0` 表示不额外等待。等待期间可取消，设置自动保存。
- 新版 passport 添加账号扫码登录流程。
- 官服抢码支持 Panda 游戏二维码两阶段登录：先解析游戏二维码，再换取 passport 二维码并确认登录。
- 启动后自动自检官服账号状态，在账号表显示 `检测中`、`有效`、`失效`、`UID异常`、`检测失败`；旧 B服记录显示 `不支持`。
- 直播间输入支持 B 站完整链接和纯房间号。
- 直播间 ID 自动保存输入历史，无需保存按钮，最近保留 5 条记录。
- 增强运行日志，固定写入 EXE 旁的 `Config/scanner.log`，包含时间、线程、出错阶段和可用错误码。

## 修复和优化

- v1.16.4 移除崩坏3 B服账号登录、B服扫码确认及其启动预取请求；B 站直播间扫码仍可使用。
- 增加账号自检、屏幕/直播启动和扫码线程的异常保护，避免相关任务异常直接终止程序。
- v1.16.3 支持 RGBA16F 浮点屏幕纹理，修复部分显卡上 `frame copy failed hr=-2147024809` 的问题。
- v1.16.2 修复直播流坏包导致识别中断，按实际帧尺寸/格式转换视频，并保留读取超时。
- 对齐确认延迟、账号和直播间输入控件，适配高 DPI 显示。
- 修复 SToken v2 校验失败问题，改用新版账号信息校验接口。
- 修复游戏二维码直接按 passport 二维码处理导致 `missing qr params` 的问题。
- 修复登录确认接口 `token_types` 参数格式错误导致 `retcode=-502` 的问题。
- 二维码参数解析从固定字符串偏移改为 query 参数解析，兼容不同二维码 URL 形态。
- 优化 B 站直播流请求头和房间号解析逻辑。
- 增加直播流初始化超时和异常日志，避免失败时界面长期无反馈。
- 移除手动保存直播间按钮，输入、点击监视和关闭窗口时自动保存。

## 功能和特性

- 从屏幕自动获取二维码登录，适用于大部分登录情景。
- 从直播流获取二维码登录，适用于抢码登录情景。
- 可选启动后自动开始识别屏幕和识别完成后自动退出。
- 表格化管理多账号，方便切换游戏账号和查看账号状态。

## 使用说明

完整解压 ZIP 到有写入权限的目录，运行带版本号的 EXE。请一起保留 DLL、`plugins` 和 `ScanModel`，不要单独复制 EXE。

点击菜单栏 **账号管理 -> 添加账号**，选择扫码、短信或 Cookie 登录添加官服账号。Cookie 格式说明见 [Cookie 登录](doc/Cookie.md)。

双击账号对应的备注单元格可以添加自定义备注。

选中账号，按需要填写 **确认延迟**，再点击 **监视屏幕**，识别支持游戏的登录二维码。手动确认时在点击“登录”后计时；启用自动确认时在识别成功后计时，随后发送确认请求。

选择直播平台，在当前直播间输入框输入直播间 ID 或 B 站直播间完整链接，点击 **监视直播间**，即可自动识别该直播间显示的二维码并自动登录。

正在执行任务的按钮会高亮显示，再次点击会停止。

## 日志与故障反馈

日志在 EXE 旁的 `Config/scanner.log`，不受快捷方式“起始位置”影响。目录无法写入时会提示。反馈问题时请附出错时间、操作步骤和日志末尾的相关记录。

可捕获的致命异常会尽量追加 `fatal:` 日志并生成带版本号的 `.dmp`。直接 fail-fast、系统强杀、启动到 `main` 之前的错误等可能绕过处理器，不能保证每次退出都有日志。转储可能包含账号内存，请勿公开上传 `.dmp`。

屏幕捕获使用 DXGI / D3D11，优先选择连接显示器的 GPU；二维码识别和当前直播视频解码仍使用 CPU，没有启用 GPU 识别推理。
