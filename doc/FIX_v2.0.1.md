# v2.0.1：二游扫码与库街区接入

## 本次变化

- 产品名称统一为“二游扫码 / ErYouScanner”；保留原 GitHub 仓库地址。
- EXE、ZIP、Windows 产品版本统一为 2.0.1，发行包只提供完整 ZIP。
- 保留本地 v2.0.0 的平台切换、界面调整、扫描间隔和确认延迟改动。
- 库街区 Token 先请求鉴权接口，成功才添加；官方网页登录使用独立 WebView2 InPrivate 窗口。
- 手机号登录支持提交官网取得的验证码；不提供未验证的一键发送账号登录短信接口。
- 撤除假二维码，不宣称支持库街区 App 扫码添加账号。
- 屏幕和直播可分别识别米哈游官服码、鸣潮官服码，账号通过稳定 provider 区分。
- 鸣潮扫码先角色预查，再按用户确认和延迟执行授权；需要短信时续交原账号、原二维码。
- 发送二次验证短信需用户点击，60 秒限流；90 秒过期保护，同账号同码 180 秒去重。
- 每次扫描、确认和短信任务绑定会话编号；取消、换账号或平台后忽略旧结果，旧排队任务不操作新会话。
- 配置原子保存；旧文件先备份再迁移，access_key 使用 Windows 当前用户 DPAPI 加密。原备份仍需私下保管。
- 日志记录请求阶段、HTTP 状态、业务码、耗时与异常类别，不写凭据和二维码。日志滚动保留约 4MB。
- 移除旧抖音请求中硬编码的浏览器 Cookie，改用匿名请求；实际直播源兼容需另行验证。
- 源码、当前运行目录、历史包、旧构建、诊断和符号分开；不再向根目录输出构建产物。

## 验证记录（2026-10-16）

- MSVC 19.44 / VS2022 x64 / Qt 6.8.0 / C++23 Release 完整编译。
- 15 项回归：库街区协议与会话、DPAPI/原子配置、确认延迟与 125%/150%/200% 界面缩放、后台异常与崩溃日志、真实 QR 模型识别、屏幕格式转换和直播帧/超时/坏包恢复。
- 另通过实际应用 UI 集成测试：隔离配置启动、平台切换、库街区添加页、非法 Token 拒绝保存、旧会话信号过滤、真实 WebView2 初始化和取消。
- 无 Token 与人工无效 Token 请求鉴权接口均返回业务 220；没有使用真实账号验证成功分支。
- ZIP 检查不含 Config、账号、日志、PDB 或 DMP；PDB 按独立构建编号保存，与 EXE/ZIP 哈希关联。

## 尚需实际账号验证

有效 Token 校验、官网和手机号真实登录、角色预查、游戏授权与二次短信验证尚未在真实账号上完成端到端验证。官网接口变化、额外人机验证、不同游戏版本的二维码内容可能影响兼容性。接口接受请求不代表游戏已经成功上线。

DPAPI 凭据绑定当前 Windows 用户；换电脑或用户后请重新登录，解密失败不会覆盖原配置。
