# v2.0.3 账号序号与重新登录

- 原因：平台切换只隐藏其他平台的行，序号仍使用全平台的实际行号。
- 修复：可见账号按平台从 1 连续编号，添加、删除和切换时刷新显示；底层账号索引及默认账号引用保持不变。
- 功能：右键账号选择“重新登录”，使用对应平台原有登录窗口；库街区仍只提供短信登录。
- 核对平台及 UID，并使用稳定账号标识定位原记录；成功后更新凭据和状态，保留备注、默认设置、顺序及账号数。
- 原账号被删除、登录到其他账号、取消或保存失败时不写入新凭据；扫描期间禁用重新登录。

验证环境：Windows x64、MSVC 19.44、C++23、Qt 6.8.0、Release 构建。

- 完整应用编译并打包成功。
- `app_ui_regression` 通过：实际 Qt 界面验证平台切换编号、删除后编号、米哈游和库街区重新登录入口、原记录更新及备注/默认设置保留。
- 回归还覆盖 UID 不匹配、取消后迟到结果、账号行移动和原记录已删除；使用临时配置及模拟凭据，不读取实际用户账号。
- 继承的短信界面测试继续覆盖真实 WebView2 初始化、模拟短信/登录、发送节流、取消及旧扫描结果隔离。
- 最终 ZIP 中 24 个运行文件哈希与清单一致，无账号配置、日志、转储或 PDB；空配置启动成功，正常退出码为 0。
- 经用户授权正常关闭旧版，更新本地 `app` 与快捷方式；539 个原配置文件逐个核对哈希一致，旧版完整归档。

真实短信送达、账号重新登录及完整游戏上线仍需实际账号验证。本地模拟测试通过不代表线上验证已完成；本记录不代表已上传 GitHub。
