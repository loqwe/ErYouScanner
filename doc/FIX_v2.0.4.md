# v2.0.4 扫码短信人机验证

已确认旧版在 `/user/sms/scanSms` 中发送空 `geeTestData`；旧界面还将不同失败统一提示成“发送未成功或不足 60 秒”。日志中相隔 60 秒的两次请求均返回 242，不能据此认定是限流，242 的官方含义仍未核实。
