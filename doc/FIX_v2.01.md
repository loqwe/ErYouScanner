# v2.01 发布记录

## 变更

- 恢复 `QRScanner` 原有的全分辨率检测输入：`WeChatQRCode::setScaleFactor(1.0)`。
- 移除 v2.00 的二维码检测缩放优化，避免改变既有扫码识别行为。
- 保留 v2.00 之前的登录、扫码、确认延迟、日志和账号管理功能。

## 版本

本版应用版本为 `2.01`，对应 EXE、ZIP 和 Windows 产品元数据统一使用 `v2.01`。

## 验证

- 版本一致性测试覆盖 CMake、Windows RC、界面版本和测试构建。
- 源码检查确认扫码检测器调用 `setScaleFactor(1.0)`。
- 实际账号登录和目标电脑上的完整扫码效果仍需手动验证。
