# 项目目录管理

项目名称：二游扫码；内部标识：`ErYouScanner`。根目录为 `D:/崩铁脚本/二游扫码`。

```text
二游扫码/
  source/                 唯一 Git 源码，包含 doc、tools 和测试
  app/                    日常运行的当前完整环境，Config 跟随此处 EXE
  releases/v<版本>/       只放对外 ZIP、校验值和对应发行记录
  symbols/v<版本>/<构建编号>/  PDB 及对应 EXE、ZIP 哈希清单
  diagnostics/            按版本、日期保存截图、报告及故障材料
  build/                  可重新生成的编译、测试和 staging 文件
  archive/                原始混合目录、旧实验构建、补丁及迁移备份
```

## 使用规则

- 日常只从 `app` 启动，根目录不再堆放 EXE、DLL、截图和临时包。
- 配置跟随当前运行目录；不要同时维护多个被当作“当前版本”的 Config。
- 发布只用版本化 ZIP，PDB 不放用户包。记录 SHA-256，保留精确对应的源码和符号；同版本重新构建生成独立符号目录，不覆盖旧 PDB。
- `build` 可再生，但清理前先确认需要保存的 PDB、报告和包已归档。旧 CMakeCache 含绝对路径，需要重新配置。
- 历史发行 ZIP 不修改内容、不解包后与当前 DLL 混用。旧实验文件先归档，不直接丢弃。
- 原有名称只在历史文档、图标资源名、兼容标识和上游来源说明中保留。旧版单实例互斥标识保留，避免旧新版同时操作配置。
- 开发依赖 `D:/mhy-build-deps` 保持原位，路径变化不等于产品改名的一部分。

## Git 与迁移

`source/.git` 是唯一仓库。迁移保留未提交的 v2.0.0 改动与历史；备份不代替正常提交。GitHub 仓库为 `loqwe/ErYouScanner`。

实际迁移以迁移清单为准，先记录来源、目标及必要校验值，再移动；日志和账号备份不进入 Git。恢复旧版时应从完整旧发行包建立独立运行目录，并明确使用哪个配置备份。

v2.0.0 保留为历史开发构建。v2.0.1 及以后通过 `source/tools/package.ps1` 生成发行包，具体参数见 [BUILD_LOCAL.md](BUILD_LOCAL.md)。
