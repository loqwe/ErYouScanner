ErYouScanner v2.0.2 adapts the SMS/GeeTest login interaction and API fields
from src/UI/WindowGeeTest.cpp, src/UI/WindowLogin.cpp and src/Core/KuRoApi.cpp.
The C++ implementation adds cancellation-safe WebView2 ownership, direct
HTML hosting, bridge origin/field validation, request timeouts, SMS cooldown,
private credential validation, and redacted diagnostics. The upstream EXE,
PDB and account/browser data are not bundled.
